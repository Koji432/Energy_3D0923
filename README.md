# Energy_3D0923 — エネルギー変換ラボ

プロペラを回すと、モータの中で何が起きるのか。装置全体とモータ内部の3D模型を同時に観察し、回転から発電、LEDの点灯までを学ぶ教材です。

固定された磁石と、軸といっしょに回る銅色のコイルを分けて表示しています。「中を見る」「分解する」を使うと、外からは見えないコイル・整流子・ブラシの位置がわかります。

## 起動方法

ビルドやnpmパッケージのインストールは不要です。リポジトリのフォルダでHTTPサーバーを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。終了するときは、サーバーを起動したターミナルで `Ctrl+C` を押します。

JavaScriptのES Modulesを使用するため、`index.html` をダブルクリックして `file://` で開く方法では動作しません。JavaScriptとWebGLが使えるブラウザが必要です。

GitHub Pagesでも、リポジトリのルートを公開対象にすればそのまま配信できます。`vendor/` を含むファイル一式を公開してください。配信時に外部CDNへ接続する必要はありません。

## 操作

| 操作                                  | 観察できること                                                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 「回してみる」／一時停止              | プロペラと内部コイルが同期して回転。停止すると発電とLEDの光も止まります。                                          |
| 「回転の速さ」スライダー              | 速く回すほど誘導電圧の振幅が大きくなります。低速ではLEDが光りにくくなります。                                      |
| 「外から」                            | カバーを付けたモータの外観を表示します。                                                                           |
| 「中を見る」                          | カバーを透かして、磁石と回転するコイルを表示します。                                                               |
| 「分解する」                          | カバーや磁石を離し、内部の部品配置を観察できます。                                                                 |
| 「磁界を表示」                        | 固定された磁石のN極からS極へ向かう矢印を表示・非表示にします。                                                     |
| 3D画面をドラッグ／スクロール          | 模型を別の方向から見る／拡大・縮小する操作です。タッチ操作は2本指で回転・拡大、1本指でページをスクロールできます。 |
| 3D画面にフォーカスして矢印キー／＋・− | キーボードでも視点変更・拡大縮小ができます。                                                                       |
| 「↺」                                 | 装置全体と内部拡大図の視点を初期状態に戻します。                                                                   |

「発電の強さ」とグラフは、コイルの向きと速さに応じて変わる整流後の電圧の目安です。1回転で2つの山が現れる様子を観察できます。

## 電磁誘導の考え方

1. 風を受けたプロペラが、モータの軸を回します。
2. モータの中では、固定された磁石の間でコイルが回転します。
3. 回転によりコイルを貫く磁束が変化すると、誘導起電力（電圧）が生じます。
4. 整流子・ブラシを通じて取り出した電気が導線を通り、LEDを光らせます。

一定の磁界で回るコイルについて、磁束は `Φ = BA cos θ`、誘導起電力は `e = −N dΦ/dt` と表せます。ここで `θ` はコイル面の法線と磁界のなす角です。磁束が大きい向きと、電圧が大きい向きは一致しません。磁束が最も速く変化する向きで、電圧の大きさが最大になります。

`physics.mjs` はこの関係を相対値で計算しています。正規化した磁束は `cos θ`、コイル内の電圧は `speed × sin θ`、整流後の出力はその絶対値です。回転角は経過秒数から進めるため、画面のフレーム数によって回転速度が変わりません。

## 模型の範囲

この教材は、コイル1組と整流子を使ったブラシ付きDCモータの発電を単純化した模式図です。実際のモータには複数の巻線や整流子片などがあり、構造と出力波形は製品によって異なります。

表示するパーセントは相対的な電圧の目安です。実物のキットで測定した電圧・電力・発電効率・回転数ではありません。LEDの明るさも、光り始めるしきい値を加えた表示用のモデルです。導線上の粒は電気の流れを示す記号で、電子の実際の移動速度を表していません。内部抵抗、負荷による速度低下、摩擦などの詳細な回路・機械計算は行っていません。

分解表示は部品を見やすくするための配置であり、その状態の磁界を再計算するものではありません。

## テスト

Node.jsの標準テストランナーを使用します。追加パッケージは不要です。

```sh
node --test physics.test.mjs
```

停止時の出力、磁束と電圧の位相、ファラデーの法則との整合性、回転方向と極性、速度とLEDの関係、フレームレートに依存しない回転、不正な入力値の扱いを検証します。
